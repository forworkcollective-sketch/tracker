# PRD: ТРЕК — Календарь + Гант в Фокус-Трекере

## Суть
Новая вкладка "ТРЕК" в TG Mini App Фокус-Трекера.
Стиль: как TickTick — переключалка видов, таймлайн с блоками задач.

## Виды (переключалка вверху)

### 1. День
- Вертикальная временная шкала 00:00–23:59
- Блоки задач на шкале (как в Google Calendar)
- Сверху: ключевые задачи дня из стратегии
- События из Apple Calendar (readonly, по .ics ссылке)
- Свободные/занятые слоты видны сразу

### 2. Неделя
- 7 колонок (ПН–ВС), строки = часы
- Блоки задач в ячейках
- Вехи стратегии отмечены маркерами сверху
- Apple Calendar события тем же способом

### 3. Месяц (30 дней)
- Сетка календаря
- Точки/метки на днях с задачами
- Гант-полоски фаз стратегии протянуты поверх сетки
- Клик на день -> раскрывает задачи дня

### 4. Гант (стратегия)
- Горизонтальные полоски фаз: Агентство, Финсвобода, Медийка, Учёба
- Внутри фаз: вехи (milestones) с датами
- Текущая дата — красная вертикальная линия
- Прогресс по каждой фазе

## UX

### Переключалка видов
Сегментированный контрол вверху: [День] [Неделя] [Месяц] [Гант]
Свайп влево/вправо — навигация по датам.

### Добавление задачи
- Тап на пустой слот в таймлайне -> модалка "новая задача"
- Время автозаполняется из слота
- Привязка к цели (goal) из Фокус-Трекера

### Интеграция с Фокус-Трекером
- Задачи = те же tasks из БД Фокус-Трекера (таблица tasks)
- Новые поля: start_time, end_time (время внутри дня)
- Таймер стартует прямо из блока задачи на таймлайне
- Выполненные задачи = зачёркнуты/затемнены

## Бэкенд

### Новая таблица: milestones
- id, phase (text), title, start_date, end_date, status (todo/done), color, priority

### Расширение таблицы tasks
- start_time (time, nullable) — начало задачи в дне
- end_time (time, nullable) — конец задачи в дне

### Apple Calendar
- Новое поле в конфиге: ICAL_URL (публичная .ics ссылка)
- Бэкенд: парсит .ics по ссылке, кеширует 15 мин
- API: GET /api/calendar/events?from=2026-05-01&to=2026-05-31

### Новые API
- GET /api/milestones — все вехи стратегии
- POST /api/milestones — создать веху
- PUT /api/milestones/:id — обновить
- DELETE /api/milestones/:id — удалить
- GET /api/calendar/day?date=2026-05-01 — задачи + события дня
- GET /api/calendar/week?date=2026-05-01 — задачи + события недели
- GET /api/calendar/month?date=2026-05 — задачи + события месяца

## Стек
- Фронт: ванильный JS в app.js (как сейчас), CSS-grid для сеток
- iCal парсинг: python icalendar библиотека
- Гант: CSS-grid + абсолютное позиционирование
- Таймлайн дня/недели: CSS-grid, строка = 30 мин

## Дизайн
- Та же палитра: бургундия + слоновая кость + glassmorphism
- Блоки задач — цвет цели (goal.color)
- Apple Calendar события — отдельный цвет (серый/синий)
- Вехи на Ганте — gradient полоски по фазам

## Деплой
- Timeweb VPS, тот же сервер что Фокус-Трекер
- nginx + certbot (HTTPS для TG Mini App)
- systemd service (уже есть tracker.service)
- pip install icalendar в venv
